# Bundled typography

Unmodified Mitr Medium (2015 Mitr Project Authors) and Sarabun Regular/SemiBold (2018 Sarabun Project Authors), from the official Google Fonts repository. Both families are distributed under SIL Open Font License 1.1. Complete copyright notices and license terms are retained beside each family as OFL.txt. They may be bundled with the game under these terms; font files must not be sold separately.

`provenance.json` records the pinned upstream commit URL and SHA256 of every downloaded font and license. No system-installed font is required for Thai game UI.

Sources: https://github.com/google/fonts/tree/main/ofl/mitr and https://github.com/google/fonts/tree/main/ofl/sarabun.

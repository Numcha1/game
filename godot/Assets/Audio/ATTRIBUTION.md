# Action audio

Five original synthesized short waveforms authored for this project by `Tools/synthesize_audio.py`: soft wood click, water droplets, harvest rustle, coin chime and refusal tone. No third-party recordings, loops or samples were used. Rebuild with Python standard library only. These are runtime action feedback, not a completed music/ambient soundscape.

Building audio: original `door.wav` latch/wood transients and `interior-ambience.wav` quiet 8-second room tone, synthesized with `Tools/synthesize_interior_audio.py` using Python standard library and a deterministic seed. No third-party recordings/samples. Effects volume/mute applies to both; final sound-mix/human acceptance remains open.

# game — สวนเพลง: Seasons Together

เกมปลูกผักบน Windows แบบ native เล่นร่วมกันทางอินเทอร์เน็ตได้สูงสุด 4 คน มีฤดูกาล สภาพอากาศ โรคพืช ช่วงเก็บเกี่ยว และแอนิเมชันการทำฟาร์ม รุ่นต้นแบบ 0.2

## ดาวน์โหลดและเล่น

ดาวน์โหลด `SuanPleng-Windows.zip` จาก [Releases](https://github.com/Numcha1/game/releases) แตกไฟล์ แล้วเปิด `SuanPleng.exe` บน Windows x64 ได้เลย ไม่ต้องติดตั้ง .NET

เจ้าของฟาร์มเลือกสร้างห้องออนไลน์ แล้วส่งลิงก์เชิญทั้งเส้นให้เพื่อน เพื่อนเปิดเกมและเลือกเข้าห้อง เจ้าของห้องต้องเปิดเกมไว้ระหว่างเล่น การเชื่อมต่อใช้ Cloudflare Quick Tunnel ลิงก์จะเปลี่ยนเมื่อสร้างห้องใหม่

เดินด้วย WASD หรือปุ่มลูกศร เลือกเครื่องมือแล้วคลิกแปลงใกล้ตัว กด E ใกล้ลังเพื่อขายผลผลิต กด Space ใกล้บ้านเพื่อนอน กด F1 ดูวิธีเล่น กด M เปิด/ปิดเสียง และ F2 ลดแอนิเมชัน

เพลง YouTube เปิดผ่านเบราว์เซอร์แยกจากตัวเกม รายละเอียดระบบและการบันทึกอยู่ใน [คู่มือเกม](native/README.md)

## สร้างไฟล์ Windows EXE

ติดตั้ง .NET SDK 8 บน Windows แล้วเปิด PowerShell ในโฟลเดอร์โปรเจกต์:

```powershell
./native/build.ps1
```

สคริปต์ดาวน์โหลด cloudflared รุ่นที่กำหนดจาก Cloudflare พร้อมตรวจ SHA-256 แล้วสร้างเกมแบบ self-contained ไปที่ `native/release/SuanPleng.exe` ไฟล์ไบนารีและเซฟเกมไม่ถูกเก็บใน Git

ตรวจระบบจำลองและเครือข่ายด้วย `SuanPleng.exe --self-test` หรือทดสอบการเชื่อมต่อผ่านอินเทอร์เน็ตด้วย `--internet-test` ส่วน `--render-test` สร้างภาพตรวจแอนิเมชันแบบไม่เปิดหน้าต่าง

## โครงสร้าง

- `native/`: ซอร์สเกม Windows C# / WinForms
- `dist/`: เกมเว็บต้นแบบเดิม เปิดผ่านเว็บเซิร์ฟเวอร์ได้
- `CLOUDFlARED-LICENSE.txt`: ใบอนุญาต Apache-2.0 ของตัวเชื่อมต่อที่รวมใน EXE
